# Krateo Blueprint — Google Cloud Redis RedisInstance

> Generated by `tools/kccgen` from the Config Connector `RedisInstance` CRD (`redis.cnrm.cloud.google.com`).

Provisions a Google Cloud Redis **RedisInstance** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `redis.cnrm.cloud.google.com/v1beta1` `RedisInstance` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpRedisInstance` Composition you create
becomes a Google Cloud RedisInstance.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector RedisInstance spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-redis-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpRedisInstance type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpRedisInstance` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpredisinstances`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-redis-instance`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpRedisInstance
metadata:
  name: my-instance
  namespace: gcp-redis-system
spec:
  projectId: my-gcp-project
  # ... RedisInstance spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpredisinstances.composition.krateo.io -n gcp-redis-system
kubectl get redisinstances.redis.cnrm.cloud.google.com -A
```
