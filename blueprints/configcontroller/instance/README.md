# Krateo Blueprint — Google Cloud Configcontroller ConfigControllerInstance

> Generated by `tools/kccgen` from the Config Connector `ConfigControllerInstance` CRD (`configcontroller.cnrm.cloud.google.com`).

Provisions a Google Cloud Configcontroller **ConfigControllerInstance** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `configcontroller.cnrm.cloud.google.com/v1beta1` `ConfigControllerInstance` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpConfigcontrollerInstance` Composition you create
becomes a Google Cloud ConfigControllerInstance.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector ConfigControllerInstance spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-configcontroller-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpConfigcontrollerInstance type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpConfigcontrollerInstance` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpconfigcontrollerinstances`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-configcontroller-instance`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpConfigcontrollerInstance
metadata:
  name: my-instance
  namespace: gcp-configcontroller-system
spec:
  projectId: my-gcp-project
  # ... ConfigControllerInstance spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpconfigcontrollerinstances.composition.krateo.io -n gcp-configcontroller-system
kubectl get configcontrollerinstances.configcontroller.cnrm.cloud.google.com -A
```
