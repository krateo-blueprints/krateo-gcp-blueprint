# Krateo Blueprint — Google Cloud Bigquery BigQueryRoutine

> Generated by `tools/kccgen` from the Config Connector `BigQueryRoutine` CRD (`bigquery.cnrm.cloud.google.com`).

Provisions a Google Cloud Bigquery **BigQueryRoutine** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `bigquery.cnrm.cloud.google.com/v1beta1` `BigQueryRoutine` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpBigqueryRoutine` Composition you create
becomes a Google Cloud BigQueryRoutine.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector BigQueryRoutine spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-bigquery-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpBigqueryRoutine type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpBigqueryRoutine` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpbigqueryroutines`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-bigquery-routine`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpBigqueryRoutine
metadata:
  name: my-routine
  namespace: gcp-bigquery-system
spec:
  projectId: my-gcp-project
  # ... BigQueryRoutine spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpbigqueryroutines.composition.krateo.io -n gcp-bigquery-system
kubectl get bigqueryroutines.bigquery.cnrm.cloud.google.com -A
```
