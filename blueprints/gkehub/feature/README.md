# Krateo Blueprint — Google Cloud Gkehub GKEHubFeature

> Generated by `tools/kccgen` from the Config Connector `GKEHubFeature` CRD (`gkehub.cnrm.cloud.google.com`).

Provisions a Google Cloud Gkehub **GKEHubFeature** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `gkehub.cnrm.cloud.google.com/v1beta1` `GKEHubFeature` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpGkehubFeature` Composition you create
becomes a Google Cloud GKEHubFeature.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector GKEHubFeature spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-gkehub-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpGkehubFeature type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpGkehubFeature` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpgkehubfeatures`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-gkehub-feature`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpGkehubFeature
metadata:
  name: my-feature
  namespace: gcp-gkehub-system
spec:
  projectId: my-gcp-project
  # ... GKEHubFeature spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpgkehubfeatures.composition.krateo.io -n gcp-gkehub-system
kubectl get gkehubfeatures.gkehub.cnrm.cloud.google.com -A
```
