# Krateo Blueprint — Google Cloud Iam IAMServiceAccountKey

> Generated by `tools/kccgen` from the Config Connector `IAMServiceAccountKey` CRD (`iam.cnrm.cloud.google.com`).

Provisions a Google Cloud Iam **IAMServiceAccountKey** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `iam.cnrm.cloud.google.com/v1beta1` `IAMServiceAccountKey` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpIamServiceaccountkey` Composition you create
becomes a Google Cloud IAMServiceAccountKey.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector IAMServiceAccountKey spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-iam-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpIamServiceaccountkey type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpIamServiceaccountkey` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpiamserviceaccountkeys`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-iam-serviceaccountkey`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpIamServiceaccountkey
metadata:
  name: my-serviceaccountkey
  namespace: gcp-iam-system
spec:
  projectId: my-gcp-project
  # ... IAMServiceAccountKey spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpiamserviceaccountkeys.composition.krateo.io -n gcp-iam-system
kubectl get iamserviceaccountkeys.iam.cnrm.cloud.google.com -A
```
