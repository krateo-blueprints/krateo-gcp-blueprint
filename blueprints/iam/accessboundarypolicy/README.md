# Krateo Blueprint — Google Cloud Iam IAMAccessBoundaryPolicy

> Generated by `tools/kccgen` from the Config Connector `IAMAccessBoundaryPolicy` CRD (`iam.cnrm.cloud.google.com`).

Provisions a Google Cloud Iam **IAMAccessBoundaryPolicy** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `iam.cnrm.cloud.google.com/v1beta1` `IAMAccessBoundaryPolicy` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpIamAccessboundarypolicy` Composition you create
becomes a Google Cloud IAMAccessBoundaryPolicy.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector IAMAccessBoundaryPolicy spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-iam-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpIamAccessboundarypolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpIamAccessboundarypolicy` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpiamaccessboundarypolicies`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-iam-accessboundarypolicy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpIamAccessboundarypolicy
metadata:
  name: my-accessboundarypolicy
  namespace: gcp-iam-system
spec:
  projectId: my-gcp-project
  # ... IAMAccessBoundaryPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpiamaccessboundarypolicies.composition.krateo.io -n gcp-iam-system
kubectl get iamaccessboundarypolicys.iam.cnrm.cloud.google.com -A
```
