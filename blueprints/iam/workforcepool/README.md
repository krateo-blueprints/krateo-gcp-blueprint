# Krateo Blueprint — Google Cloud Iam IAMWorkforcePool

> Generated by `tools/kccgen` from the Config Connector `IAMWorkforcePool` CRD (`iam.cnrm.cloud.google.com`).

Provisions a Google Cloud Iam **IAMWorkforcePool** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `iam.cnrm.cloud.google.com/v1beta1` `IAMWorkforcePool` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpIamWorkforcepool` Composition you create
becomes a Google Cloud IAMWorkforcePool.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector IAMWorkforcePool spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-iam-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpIamWorkforcepool type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpIamWorkforcepool` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpiamworkforcepools`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-iam-workforcepool`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpIamWorkforcepool
metadata:
  name: my-workforcepool
  namespace: gcp-iam-system
spec:
  projectId: my-gcp-project
  # ... IAMWorkforcePool spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpiamworkforcepools.composition.krateo.io -n gcp-iam-system
kubectl get iamworkforcepools.iam.cnrm.cloud.google.com -A
```
