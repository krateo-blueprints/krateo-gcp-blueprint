# Krateo Blueprint — Google Cloud Artifactregistry ArtifactRegistryRepository

> Generated by `tools/kccgen` from the Config Connector `ArtifactRegistryRepository` CRD (`artifactregistry.cnrm.cloud.google.com`).

Provisions a Google Cloud Artifactregistry **ArtifactRegistryRepository** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `artifactregistry.cnrm.cloud.google.com/v1beta1` `ArtifactRegistryRepository` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpArtifactregistryRepository` Composition you create
becomes a Google Cloud ArtifactRegistryRepository.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector ArtifactRegistryRepository spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-artifactregistry-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpArtifactregistryRepository type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpArtifactregistryRepository` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpartifactregistryrepositories`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-artifactregistry-repository`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpArtifactregistryRepository
metadata:
  name: my-repository
  namespace: gcp-artifactregistry-system
spec:
  projectId: my-gcp-project
  # ... ArtifactRegistryRepository spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpartifactregistryrepositories.composition.krateo.io -n gcp-artifactregistry-system
kubectl get artifactregistryrepositorys.artifactregistry.cnrm.cloud.google.com -A
```
