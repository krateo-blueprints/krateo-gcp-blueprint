# Krateo Blueprint — Google Cloud Vpcaccess VPCAccessConnector

> Generated by `tools/kccgen` from the Config Connector `VPCAccessConnector` CRD (`vpcaccess.cnrm.cloud.google.com`).

Provisions a Google Cloud Vpcaccess **VPCAccessConnector** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `vpcaccess.cnrm.cloud.google.com/v1beta1` `VPCAccessConnector` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpVpcaccessConnector` Composition you create
becomes a Google Cloud VPCAccessConnector.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector VPCAccessConnector spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-vpcaccess-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpVpcaccessConnector type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpVpcaccessConnector` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpvpcaccessconnectors`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-vpcaccess-connector`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpVpcaccessConnector
metadata:
  name: my-connector
  namespace: gcp-vpcaccess-system
spec:
  projectId: my-gcp-project
  # ... VPCAccessConnector spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpvpcaccessconnectors.composition.krateo.io -n gcp-vpcaccess-system
kubectl get vpcaccessconnectors.vpcaccess.cnrm.cloud.google.com -A
```
