# Krateo Blueprint — Google Cloud Identityplatform IdentityPlatformTenantOAuthIDPConfig

> Generated by `tools/kccgen` from the Config Connector `IdentityPlatformTenantOAuthIDPConfig` CRD (`identityplatform.cnrm.cloud.google.com`).

Provisions a Google Cloud Identityplatform **IdentityPlatformTenantOAuthIDPConfig** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `identityplatform.cnrm.cloud.google.com/v1beta1` `IdentityPlatformTenantOAuthIDPConfig` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpIdentityplatformTenantoauthidpconfig` Composition you create
becomes a Google Cloud IdentityPlatformTenantOAuthIDPConfig.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector IdentityPlatformTenantOAuthIDPConfig spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-identityplatform-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpIdentityplatformTenantoauthidpconfig type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpIdentityplatformTenantoauthidpconfig` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpidentityplatformtenantoauthidpconfigs`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-identityplatform-tenantoauthidpconfig`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpIdentityplatformTenantoauthidpconfig
metadata:
  name: my-tenantoauthidpconfig
  namespace: gcp-identityplatform-system
spec:
  projectId: my-gcp-project
  # ... IdentityPlatformTenantOAuthIDPConfig spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpidentityplatformtenantoauthidpconfigs.composition.krateo.io -n gcp-identityplatform-system
kubectl get identityplatformtenantoauthidpconfigs.identityplatform.cnrm.cloud.google.com -A
```
