# Krateo Blueprint — Google Cloud Identityplatform IdentityPlatformConfig

> Generated by `tools/kccgen` from the Config Connector `IdentityPlatformConfig` CRD (`identityplatform.cnrm.cloud.google.com`).

Provisions a Google Cloud Identityplatform **IdentityPlatformConfig** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `identityplatform.cnrm.cloud.google.com/v1beta1` `IdentityPlatformConfig` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpIdentityplatformConfig` Composition you create
becomes a Google Cloud IdentityPlatformConfig.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector IdentityPlatformConfig spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-identityplatform-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpIdentityplatformConfig type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpIdentityplatformConfig` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpidentityplatformconfigs`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-identityplatform-config`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpIdentityplatformConfig
metadata:
  name: my-config
  namespace: gcp-identityplatform-system
spec:
  projectId: my-gcp-project
  # ... IdentityPlatformConfig spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpidentityplatformconfigs.composition.krateo.io -n gcp-identityplatform-system
kubectl get identityplatformconfigs.identityplatform.cnrm.cloud.google.com -A
```
