# Krateo Blueprint — Google Cloud Dataform DataformRepository

> Generated by `tools/kccgen` from the Config Connector `DataformRepository` CRD (`dataform.cnrm.cloud.google.com`).

Provisions a Google Cloud Dataform **DataformRepository** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `dataform.cnrm.cloud.google.com/v1beta1` `DataformRepository` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpDataformRepository` Composition you create
becomes a Google Cloud DataformRepository.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector DataformRepository spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-dataform-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpDataformRepository type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpDataformRepository` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpdataformrepositories`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-dataform-repository`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpDataformRepository
metadata:
  name: my-repository
  namespace: gcp-dataform-system
spec:
  projectId: my-gcp-project
  # ... DataformRepository spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpdataformrepositories.composition.krateo.io -n gcp-dataform-system
kubectl get dataformrepositorys.dataform.cnrm.cloud.google.com -A
```
