# Krateo Blueprint — Google Cloud Cloudbuild CloudBuildTrigger

> Generated by `tools/kccgen` from the Config Connector `CloudBuildTrigger` CRD (`cloudbuild.cnrm.cloud.google.com`).

Provisions a Google Cloud Cloudbuild **CloudBuildTrigger** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `cloudbuild.cnrm.cloud.google.com/v1beta1` `CloudBuildTrigger` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpCloudbuildTrigger` Composition you create
becomes a Google Cloud CloudBuildTrigger.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector CloudBuildTrigger spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-cloudbuild-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpCloudbuildTrigger type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpCloudbuildTrigger` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpcloudbuildtriggers`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-cloudbuild-trigger`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpCloudbuildTrigger
metadata:
  name: my-trigger
  namespace: gcp-cloudbuild-system
spec:
  projectId: my-gcp-project
  # ... CloudBuildTrigger spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpcloudbuildtriggers.composition.krateo.io -n gcp-cloudbuild-system
kubectl get cloudbuildtriggers.cloudbuild.cnrm.cloud.google.com -A
```
