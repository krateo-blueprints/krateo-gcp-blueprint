# Krateo Blueprint — Google Cloud Accesscontextmanager AccessContextManagerAccessPolicy

> Generated by `tools/kccgen` from the Config Connector `AccessContextManagerAccessPolicy` CRD (`accesscontextmanager.cnrm.cloud.google.com`).

Provisions a Google Cloud Accesscontextmanager **AccessContextManagerAccessPolicy** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `accesscontextmanager.cnrm.cloud.google.com/v1beta1` `AccessContextManagerAccessPolicy` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpAccesscontextmanagerAccesspolicy` Composition you create
becomes a Google Cloud AccessContextManagerAccessPolicy.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector AccessContextManagerAccessPolicy spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-accesscontextmanager-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpAccesscontextmanagerAccesspolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpAccesscontextmanagerAccesspolicy` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpaccesscontextmanageraccesspolicies`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-accesscontextmanager-accesspolicy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpAccesscontextmanagerAccesspolicy
metadata:
  name: my-accesspolicy
  namespace: gcp-accesscontextmanager-system
spec:
  projectId: my-gcp-project
  # ... AccessContextManagerAccessPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpaccesscontextmanageraccesspolicies.composition.krateo.io -n gcp-accesscontextmanager-system
kubectl get accesscontextmanageraccesspolicys.accesscontextmanager.cnrm.cloud.google.com -A
```
