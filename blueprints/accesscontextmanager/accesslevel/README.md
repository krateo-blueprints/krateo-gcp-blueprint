# Krateo Blueprint — Google Cloud Accesscontextmanager AccessContextManagerAccessLevel

> Generated by `tools/kccgen` from the Config Connector `AccessContextManagerAccessLevel` CRD (`accesscontextmanager.cnrm.cloud.google.com`).

Provisions a Google Cloud Accesscontextmanager **AccessContextManagerAccessLevel** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `accesscontextmanager.cnrm.cloud.google.com/v1beta1` `AccessContextManagerAccessLevel` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpAccesscontextmanagerAccesslevel` Composition you create
becomes a Google Cloud AccessContextManagerAccessLevel.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector AccessContextManagerAccessLevel spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-accesscontextmanager-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpAccesscontextmanagerAccesslevel type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpAccesscontextmanagerAccesslevel` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpaccesscontextmanageraccesslevels`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-accesscontextmanager-accesslevel`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpAccesscontextmanagerAccesslevel
metadata:
  name: my-accesslevel
  namespace: gcp-accesscontextmanager-system
spec:
  projectId: my-gcp-project
  # ... AccessContextManagerAccessLevel spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpaccesscontextmanageraccesslevels.composition.krateo.io -n gcp-accesscontextmanager-system
kubectl get accesscontextmanageraccesslevels.accesscontextmanager.cnrm.cloud.google.com -A
```
