# Krateo Blueprint — Google Cloud Iap IAPIdentityAwareProxyClient

> Generated by `tools/kccgen` from the Config Connector `IAPIdentityAwareProxyClient` CRD (`iap.cnrm.cloud.google.com`).

Provisions a Google Cloud Iap **IAPIdentityAwareProxyClient** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `iap.cnrm.cloud.google.com/v1beta1` `IAPIdentityAwareProxyClient` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpIapIdentityawareproxyclient` Composition you create
becomes a Google Cloud IAPIdentityAwareProxyClient.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector IAPIdentityAwareProxyClient spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-iap-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpIapIdentityawareproxyclient type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpIapIdentityawareproxyclient` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpiapidentityawareproxyclients`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-iap-identityawareproxyclient`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpIapIdentityawareproxyclient
metadata:
  name: my-identityawareproxyclient
  namespace: gcp-iap-system
spec:
  projectId: my-gcp-project
  # ... IAPIdentityAwareProxyClient spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpiapidentityawareproxyclients.composition.krateo.io -n gcp-iap-system
kubectl get iapidentityawareproxyclients.iap.cnrm.cloud.google.com -A
```
