# Krateo Blueprint — Google Cloud Compute ComputeInstanceGroup

> Generated by `tools/kccgen` from the Config Connector `ComputeInstanceGroup` CRD (`compute.cnrm.cloud.google.com`).

Provisions a Google Cloud Compute **ComputeInstanceGroup** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `compute.cnrm.cloud.google.com/v1beta1` `ComputeInstanceGroup` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpComputeInstancegroup` Composition you create
becomes a Google Cloud ComputeInstanceGroup.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector ComputeInstanceGroup spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-compute-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpComputeInstancegroup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpComputeInstancegroup` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpcomputeinstancegroups`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-compute-instancegroup`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpComputeInstancegroup
metadata:
  name: my-instancegroup
  namespace: gcp-compute-system
spec:
  projectId: my-gcp-project
  # ... ComputeInstanceGroup spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpcomputeinstancegroups.composition.krateo.io -n gcp-compute-system
kubectl get computeinstancegroups.compute.cnrm.cloud.google.com -A
```
