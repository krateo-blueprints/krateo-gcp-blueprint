# Krateo Blueprint — Google Cloud Compute ComputeSnapshot

> Generated by `tools/kccgen` from the Config Connector `ComputeSnapshot` CRD (`compute.cnrm.cloud.google.com`).

Provisions a Google Cloud Compute **ComputeSnapshot** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `compute.cnrm.cloud.google.com/v1beta1` `ComputeSnapshot` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpComputeSnapshot` Composition you create
becomes a Google Cloud ComputeSnapshot.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector ComputeSnapshot spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-compute-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpComputeSnapshot type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpComputeSnapshot` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpcomputesnapshots`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-compute-snapshot`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpComputeSnapshot
metadata:
  name: my-snapshot
  namespace: gcp-compute-system
spec:
  projectId: my-gcp-project
  # ... ComputeSnapshot spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpcomputesnapshots.composition.krateo.io -n gcp-compute-system
kubectl get computesnapshots.compute.cnrm.cloud.google.com -A
```
