# Krateo Blueprint — Google Cloud Containeranalysis ContainerAnalysisNote

> Generated by `tools/kccgen` from the Config Connector `ContainerAnalysisNote` CRD (`containeranalysis.cnrm.cloud.google.com`).

Provisions a Google Cloud Containeranalysis **ContainerAnalysisNote** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `containeranalysis.cnrm.cloud.google.com/v1beta1` `ContainerAnalysisNote` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpContaineranalysisNote` Composition you create
becomes a Google Cloud ContainerAnalysisNote.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector ContainerAnalysisNote spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-containeranalysis-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpContaineranalysisNote type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpContaineranalysisNote` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpcontaineranalysisnotes`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-containeranalysis-note`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpContaineranalysisNote
metadata:
  name: my-note
  namespace: gcp-containeranalysis-system
spec:
  projectId: my-gcp-project
  # ... ContainerAnalysisNote spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpcontaineranalysisnotes.composition.krateo.io -n gcp-containeranalysis-system
kubectl get containeranalysisnotes.containeranalysis.cnrm.cloud.google.com -A
```
