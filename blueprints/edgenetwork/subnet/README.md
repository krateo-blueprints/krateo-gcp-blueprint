# Krateo Blueprint — Google Cloud Edgenetwork EdgeNetworkSubnet

> Generated by `tools/kccgen` from the Config Connector `EdgeNetworkSubnet` CRD (`edgenetwork.cnrm.cloud.google.com`).

Provisions a Google Cloud Edgenetwork **EdgeNetworkSubnet** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `edgenetwork.cnrm.cloud.google.com/v1beta1` `EdgeNetworkSubnet` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpEdgenetworkSubnet` Composition you create
becomes a Google Cloud EdgeNetworkSubnet.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector EdgeNetworkSubnet spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-edgenetwork-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpEdgenetworkSubnet type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpEdgenetworkSubnet` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpedgenetworksubnets`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-edgenetwork-subnet`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpEdgenetworkSubnet
metadata:
  name: my-subnet
  namespace: gcp-edgenetwork-system
spec:
  projectId: my-gcp-project
  # ... EdgeNetworkSubnet spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpedgenetworksubnets.composition.krateo.io -n gcp-edgenetwork-system
kubectl get edgenetworksubnets.edgenetwork.cnrm.cloud.google.com -A
```
