# Krateo Blueprint — Google Cloud Pubsublite PubSubLiteReservation

> Generated by `tools/kccgen` from the Config Connector `PubSubLiteReservation` CRD (`pubsublite.cnrm.cloud.google.com`).

Provisions a Google Cloud Pubsublite **PubSubLiteReservation** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `pubsublite.cnrm.cloud.google.com/v1beta1` `PubSubLiteReservation` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpPubsubliteReservation` Composition you create
becomes a Google Cloud PubSubLiteReservation.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector PubSubLiteReservation spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-pubsublite-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpPubsubliteReservation type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpPubsubliteReservation` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcppubsublitereservations`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-pubsublite-reservation`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpPubsubliteReservation
metadata:
  name: my-reservation
  namespace: gcp-pubsublite-system
spec:
  projectId: my-gcp-project
  # ... PubSubLiteReservation spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcppubsublitereservations.composition.krateo.io -n gcp-pubsublite-system
kubectl get pubsublitereservations.pubsublite.cnrm.cloud.google.com -A
```
