# Krateo Blueprint — Google Cloud Networksecurity NetworkSecurityAuthorizationPolicy

> Generated by `tools/kccgen` from the Config Connector `NetworkSecurityAuthorizationPolicy` CRD (`networksecurity.cnrm.cloud.google.com`).

Provisions a Google Cloud Networksecurity **NetworkSecurityAuthorizationPolicy** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `networksecurity.cnrm.cloud.google.com/v1beta1` `NetworkSecurityAuthorizationPolicy` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpNetworksecurityAuthorizationpolicy` Composition you create
becomes a Google Cloud NetworkSecurityAuthorizationPolicy.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector NetworkSecurityAuthorizationPolicy spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-networksecurity-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpNetworksecurityAuthorizationpolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpNetworksecurityAuthorizationpolicy` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpnetworksecurityauthorizationpolicies`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-networksecurity-authorizationpolicy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpNetworksecurityAuthorizationpolicy
metadata:
  name: my-authorizationpolicy
  namespace: gcp-networksecurity-system
spec:
  projectId: my-gcp-project
  # ... NetworkSecurityAuthorizationPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpnetworksecurityauthorizationpolicies.composition.krateo.io -n gcp-networksecurity-system
kubectl get networksecurityauthorizationpolicys.networksecurity.cnrm.cloud.google.com -A
```
