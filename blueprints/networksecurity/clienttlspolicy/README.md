# Krateo Blueprint — Google Cloud Networksecurity NetworkSecurityClientTLSPolicy

> Generated by `tools/kccgen` from the Config Connector `NetworkSecurityClientTLSPolicy` CRD (`networksecurity.cnrm.cloud.google.com`).

Provisions a Google Cloud Networksecurity **NetworkSecurityClientTLSPolicy** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `networksecurity.cnrm.cloud.google.com/v1beta1` `NetworkSecurityClientTLSPolicy` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpNetworksecurityClienttlspolicy` Composition you create
becomes a Google Cloud NetworkSecurityClientTLSPolicy.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector NetworkSecurityClientTLSPolicy spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-networksecurity-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpNetworksecurityClienttlspolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpNetworksecurityClienttlspolicy` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpnetworksecurityclienttlspolicies`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-networksecurity-clienttlspolicy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpNetworksecurityClienttlspolicy
metadata:
  name: my-clienttlspolicy
  namespace: gcp-networksecurity-system
spec:
  projectId: my-gcp-project
  # ... NetworkSecurityClientTLSPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpnetworksecurityclienttlspolicies.composition.krateo.io -n gcp-networksecurity-system
kubectl get networksecurityclienttlspolicys.networksecurity.cnrm.cloud.google.com -A
```
