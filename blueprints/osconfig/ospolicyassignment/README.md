# Krateo Blueprint — Google Cloud Osconfig OSConfigOSPolicyAssignment

> Generated by `tools/kccgen` from the Config Connector `OSConfigOSPolicyAssignment` CRD (`osconfig.cnrm.cloud.google.com`).

Provisions a Google Cloud Osconfig **OSConfigOSPolicyAssignment** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `osconfig.cnrm.cloud.google.com/v1beta1` `OSConfigOSPolicyAssignment` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpOsconfigOspolicyassignment` Composition you create
becomes a Google Cloud OSConfigOSPolicyAssignment.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector OSConfigOSPolicyAssignment spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-osconfig-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpOsconfigOspolicyassignment type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpOsconfigOspolicyassignment` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcposconfigospolicyassignments`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-osconfig-ospolicyassignment`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpOsconfigOspolicyassignment
metadata:
  name: my-ospolicyassignment
  namespace: gcp-osconfig-system
spec:
  projectId: my-gcp-project
  # ... OSConfigOSPolicyAssignment spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcposconfigospolicyassignments.composition.krateo.io -n gcp-osconfig-system
kubectl get osconfigospolicyassignments.osconfig.cnrm.cloud.google.com -A
```
