# Krateo Blueprint — Google Cloud Bigtable BigtableGCPolicy

> Generated by `tools/kccgen` from the Config Connector `BigtableGCPolicy` CRD (`bigtable.cnrm.cloud.google.com`).

Provisions a Google Cloud Bigtable **BigtableGCPolicy** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `bigtable.cnrm.cloud.google.com/v1beta1` `BigtableGCPolicy` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpBigtableGcpolicy` Composition you create
becomes a Google Cloud BigtableGCPolicy.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector BigtableGCPolicy spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-bigtable-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpBigtableGcpolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpBigtableGcpolicy` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpbigtablegcpolicies`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-bigtable-gcpolicy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpBigtableGcpolicy
metadata:
  name: my-gcpolicy
  namespace: gcp-bigtable-system
spec:
  projectId: my-gcp-project
  # ... BigtableGCPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpbigtablegcpolicies.composition.krateo.io -n gcp-bigtable-system
kubectl get bigtablegcpolicys.bigtable.cnrm.cloud.google.com -A
```
