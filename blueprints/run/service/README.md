# Krateo Blueprint — Google Cloud Run RunService

> Generated by `tools/kccgen` from the Config Connector `RunService` CRD (`run.cnrm.cloud.google.com`).

Provisions a Google Cloud Run **RunService** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `run.cnrm.cloud.google.com/v1beta1` `RunService` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpRunService` Composition you create
becomes a Google Cloud RunService.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector RunService spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-run-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpRunService type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpRunService` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcprunservices`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-run-service`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpRunService
metadata:
  name: my-service
  namespace: gcp-run-system
spec:
  projectId: my-gcp-project
  # ... RunService spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcprunservices.composition.krateo.io -n gcp-run-system
kubectl get runservices.run.cnrm.cloud.google.com -A
```
