# Krateo Blueprint — Google Cloud Dlp DLPStoredInfoType

> Generated by `tools/kccgen` from the Config Connector `DLPStoredInfoType` CRD (`dlp.cnrm.cloud.google.com`).

Provisions a Google Cloud Dlp **DLPStoredInfoType** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `dlp.cnrm.cloud.google.com/v1beta1` `DLPStoredInfoType` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpDlpStoredinfotype` Composition you create
becomes a Google Cloud DLPStoredInfoType.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector DLPStoredInfoType spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-dlp-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpDlpStoredinfotype type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpDlpStoredinfotype` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpdlpstoredinfotypes`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-dlp-storedinfotype`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpDlpStoredinfotype
metadata:
  name: my-storedinfotype
  namespace: gcp-dlp-system
spec:
  projectId: my-gcp-project
  # ... DLPStoredInfoType spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpdlpstoredinfotypes.composition.krateo.io -n gcp-dlp-system
kubectl get dlpstoredinfotypes.dlp.cnrm.cloud.google.com -A
```
