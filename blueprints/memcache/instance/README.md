# Krateo Blueprint — Google Cloud Memcache MemcacheInstance

> Generated by `tools/kccgen` from the Config Connector `MemcacheInstance` CRD (`memcache.cnrm.cloud.google.com`).

Provisions a Google Cloud Memcache **MemcacheInstance** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `memcache.cnrm.cloud.google.com/v1beta1` `MemcacheInstance` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpMemcacheInstance` Composition you create
becomes a Google Cloud MemcacheInstance.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector MemcacheInstance spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-memcache-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpMemcacheInstance type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpMemcacheInstance` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpmemcacheinstances`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-memcache-instance`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpMemcacheInstance
metadata:
  name: my-instance
  namespace: gcp-memcache-system
spec:
  projectId: my-gcp-project
  # ... MemcacheInstance spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpmemcacheinstances.composition.krateo.io -n gcp-memcache-system
kubectl get memcacheinstances.memcache.cnrm.cloud.google.com -A
```
