# Krateo Blueprint — Google Cloud Networkconnectivity NetworkConnectivitySpoke

> Generated by `tools/kccgen` from the Config Connector `NetworkConnectivitySpoke` CRD (`networkconnectivity.cnrm.cloud.google.com`).

Provisions a Google Cloud Networkconnectivity **NetworkConnectivitySpoke** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `networkconnectivity.cnrm.cloud.google.com/v1beta1` `NetworkConnectivitySpoke` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpNetworkconnectivitySpoke` Composition you create
becomes a Google Cloud NetworkConnectivitySpoke.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector NetworkConnectivitySpoke spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-networkconnectivity-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpNetworkconnectivitySpoke type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpNetworkconnectivitySpoke` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpnetworkconnectivityspokes`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-networkconnectivity-spoke`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpNetworkconnectivitySpoke
metadata:
  name: my-spoke
  namespace: gcp-networkconnectivity-system
spec:
  projectId: my-gcp-project
  # ... NetworkConnectivitySpoke spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpnetworkconnectivityspokes.composition.krateo.io -n gcp-networkconnectivity-system
kubectl get networkconnectivityspokes.networkconnectivity.cnrm.cloud.google.com -A
```
