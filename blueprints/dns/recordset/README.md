# Krateo Blueprint — Google Cloud Dns DNSRecordSet

> Generated by `tools/kccgen` from the Config Connector `DNSRecordSet` CRD (`dns.cnrm.cloud.google.com`).

Provisions a Google Cloud Dns **DNSRecordSet** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `dns.cnrm.cloud.google.com/v1beta1` `DNSRecordSet` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpDNSRecordset` Composition you create
becomes a Google Cloud DNSRecordSet.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector DNSRecordSet spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-dns-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpDNSRecordset type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpDNSRecordset` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpdnsrecordsets`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-dns-recordset`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpDNSRecordset
metadata:
  name: my-recordset
  namespace: gcp-dns-system
spec:
  projectId: my-gcp-project
  # ... DNSRecordSet spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpdnsrecordsets.composition.krateo.io -n gcp-dns-system
kubectl get dnsrecordsets.dns.cnrm.cloud.google.com -A
```
