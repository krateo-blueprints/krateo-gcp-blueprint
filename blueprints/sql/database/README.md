# Krateo Blueprint — Google Cloud Sql SQLDatabase

> Generated by `tools/kccgen` from the Config Connector `SQLDatabase` CRD (`sql.cnrm.cloud.google.com`).

Provisions a Google Cloud Sql **SQLDatabase** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `sql.cnrm.cloud.google.com/v1beta1` `SQLDatabase` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpSQLDatabase` Composition you create
becomes a Google Cloud SQLDatabase.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector SQLDatabase spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-sql-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpSQLDatabase type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpSQLDatabase` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpsqldatabases`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-sql-database`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpSQLDatabase
metadata:
  name: my-database
  namespace: gcp-sql-system
spec:
  projectId: my-gcp-project
  # ... SQLDatabase spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpsqldatabases.composition.krateo.io -n gcp-sql-system
kubectl get sqldatabases.sql.cnrm.cloud.google.com -A
```
