# Krateo Blueprint — Google Cloud Cloudids CloudIDSEndpoint

> Generated by `tools/kccgen` from the Config Connector `CloudIDSEndpoint` CRD (`cloudids.cnrm.cloud.google.com`).

Provisions a Google Cloud Cloudids **CloudIDSEndpoint** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `cloudids.cnrm.cloud.google.com/v1alpha1` `CloudIDSEndpoint` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpCloudidsEndpoint` Composition you create
becomes a Google Cloud CloudIDSEndpoint.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector CloudIDSEndpoint spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-cloudids-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpCloudidsEndpoint type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpCloudidsEndpoint` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpcloudidsendpoints`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-cloudids-endpoint`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpCloudidsEndpoint
metadata:
  name: my-endpoint
  namespace: gcp-cloudids-system
spec:
  projectId: my-gcp-project
  # ... CloudIDSEndpoint spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpcloudidsendpoints.composition.krateo.io -n gcp-cloudids-system
kubectl get cloudidsendpoints.cloudids.cnrm.cloud.google.com -A
```
