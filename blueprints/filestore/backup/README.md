# Krateo Blueprint — Google Cloud Filestore FilestoreBackup

> Generated by `tools/kccgen` from the Config Connector `FilestoreBackup` CRD (`filestore.cnrm.cloud.google.com`).

Provisions a Google Cloud Filestore **FilestoreBackup** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `filestore.cnrm.cloud.google.com/v1beta1` `FilestoreBackup` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpFilestoreBackup` Composition you create
becomes a Google Cloud FilestoreBackup.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector FilestoreBackup spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-filestore-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpFilestoreBackup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpFilestoreBackup` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpfilestorebackups`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-filestore-backup`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpFilestoreBackup
metadata:
  name: my-backup
  namespace: gcp-filestore-system
spec:
  projectId: my-gcp-project
  # ... FilestoreBackup spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpfilestorebackups.composition.krateo.io -n gcp-filestore-system
kubectl get filestorebackups.filestore.cnrm.cloud.google.com -A
```
