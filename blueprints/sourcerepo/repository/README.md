# Krateo Blueprint — Google Cloud Sourcerepo SourceRepoRepository

> Generated by `tools/kccgen` from the Config Connector `SourceRepoRepository` CRD (`sourcerepo.cnrm.cloud.google.com`).

Provisions a Google Cloud Sourcerepo **SourceRepoRepository** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `sourcerepo.cnrm.cloud.google.com/v1beta1` `SourceRepoRepository` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpSourcerepoRepository` Composition you create
becomes a Google Cloud SourceRepoRepository.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector SourceRepoRepository spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-sourcerepo-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpSourcerepoRepository type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpSourcerepoRepository` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpsourcereporepositories`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-sourcerepo-repository`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpSourcerepoRepository
metadata:
  name: my-repository
  namespace: gcp-sourcerepo-system
spec:
  projectId: my-gcp-project
  # ... SourceRepoRepository spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpsourcereporepositories.composition.krateo.io -n gcp-sourcerepo-system
kubectl get sourcereporepositorys.sourcerepo.cnrm.cloud.google.com -A
```
