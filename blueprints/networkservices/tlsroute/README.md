# Krateo Blueprint — Google Cloud Networkservices NetworkServicesTLSRoute

> Generated by `tools/kccgen` from the Config Connector `NetworkServicesTLSRoute` CRD (`networkservices.cnrm.cloud.google.com`).

Provisions a Google Cloud Networkservices **NetworkServicesTLSRoute** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `networkservices.cnrm.cloud.google.com/v1beta1` `NetworkServicesTLSRoute` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpNetworkservicesTlsroute` Composition you create
becomes a Google Cloud NetworkServicesTLSRoute.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector NetworkServicesTLSRoute spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-networkservices-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpNetworkservicesTlsroute type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpNetworkservicesTlsroute` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpnetworkservicestlsroutes`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-networkservices-tlsroute`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpNetworkservicesTlsroute
metadata:
  name: my-tlsroute
  namespace: gcp-networkservices-system
spec:
  projectId: my-gcp-project
  # ... NetworkServicesTLSRoute spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpnetworkservicestlsroutes.composition.krateo.io -n gcp-networkservices-system
kubectl get networkservicestlsroutes.networkservices.cnrm.cloud.google.com -A
```
