# Krateo Blueprint — Google Cloud Pubsub PubSubSubscription

> Generated by `tools/kccgen` from the Config Connector `PubSubSubscription` CRD (`pubsub.cnrm.cloud.google.com`).

Provisions a Google Cloud Pubsub **PubSubSubscription** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `pubsub.cnrm.cloud.google.com/v1beta1` `PubSubSubscription` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpPubsubSubscription` Composition you create
becomes a Google Cloud PubSubSubscription.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector PubSubSubscription spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-pubsub-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpPubsubSubscription type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpPubsubSubscription` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcppubsubsubscriptions`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-pubsub-subscription`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpPubsubSubscription
metadata:
  name: my-subscription
  namespace: gcp-pubsub-system
spec:
  projectId: my-gcp-project
  # ... PubSubSubscription spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcppubsubsubscriptions.composition.krateo.io -n gcp-pubsub-system
kubectl get pubsubsubscriptions.pubsub.cnrm.cloud.google.com -A
```
