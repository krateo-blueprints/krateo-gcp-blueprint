# Krateo Blueprint — Google Cloud Datacatalog DataCatalogTaxonomy

> Generated by `tools/kccgen` from the Config Connector `DataCatalogTaxonomy` CRD (`datacatalog.cnrm.cloud.google.com`).

Provisions a Google Cloud Datacatalog **DataCatalogTaxonomy** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `datacatalog.cnrm.cloud.google.com/v1beta1` `DataCatalogTaxonomy` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpDatacatalogTaxonomy` Composition you create
becomes a Google Cloud DataCatalogTaxonomy.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector DataCatalogTaxonomy spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-datacatalog-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpDatacatalogTaxonomy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpDatacatalogTaxonomy` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpdatacatalogtaxonomies`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-datacatalog-taxonomy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpDatacatalogTaxonomy
metadata:
  name: my-taxonomy
  namespace: gcp-datacatalog-system
spec:
  projectId: my-gcp-project
  # ... DataCatalogTaxonomy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpdatacatalogtaxonomies.composition.krateo.io -n gcp-datacatalog-system
kubectl get datacatalogtaxonomys.datacatalog.cnrm.cloud.google.com -A
```
