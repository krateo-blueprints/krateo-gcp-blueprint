# Krateo Blueprint — Google Cloud Kms KMSCryptoKey

> Generated by `tools/kccgen` from the Config Connector `KMSCryptoKey` CRD (`kms.cnrm.cloud.google.com`).

Provisions a Google Cloud Kms **KMSCryptoKey** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `kms.cnrm.cloud.google.com/v1beta1` `KMSCryptoKey` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpKmsCryptokey` Composition you create
becomes a Google Cloud KMSCryptoKey.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector KMSCryptoKey spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-kms-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpKmsCryptokey type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpKmsCryptokey` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpkmscryptokeys`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-kms-cryptokey`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpKmsCryptokey
metadata:
  name: my-cryptokey
  namespace: gcp-kms-system
spec:
  projectId: my-gcp-project
  # ... KMSCryptoKey spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpkmscryptokeys.composition.krateo.io -n gcp-kms-system
kubectl get kmscryptokeys.kms.cnrm.cloud.google.com -A
```
