# Krateo Blueprint — Google Cloud Kms KMSKeyRing

> Generated by `tools/kccgen` from the Config Connector `KMSKeyRing` CRD (`kms.cnrm.cloud.google.com`).

Provisions a Google Cloud Kms **KMSKeyRing** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `kms.cnrm.cloud.google.com/v1beta1` `KMSKeyRing` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpKmsKeyring` Composition you create
becomes a Google Cloud KMSKeyRing.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector KMSKeyRing spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-kms-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpKmsKeyring type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpKmsKeyring` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpkmskeyrings`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-kms-keyring`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpKmsKeyring
metadata:
  name: my-keyring
  namespace: gcp-kms-system
spec:
  projectId: my-gcp-project
  # ... KMSKeyRing spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpkmskeyrings.composition.krateo.io -n gcp-kms-system
kubectl get kmskeyrings.kms.cnrm.cloud.google.com -A
```
