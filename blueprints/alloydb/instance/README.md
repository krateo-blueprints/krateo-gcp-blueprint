# Krateo Blueprint — Google Cloud Alloydb AlloyDBInstance

> Generated by `tools/kccgen` from the Config Connector `AlloyDBInstance` CRD (`alloydb.cnrm.cloud.google.com`).

Provisions a Google Cloud Alloydb **AlloyDBInstance** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `alloydb.cnrm.cloud.google.com/v1beta1` `AlloyDBInstance` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpAlloydbInstance` Composition you create
becomes a Google Cloud AlloyDBInstance.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector AlloyDBInstance spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-alloydb-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpAlloydbInstance type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpAlloydbInstance` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpalloydbinstances`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-alloydb-instance`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpAlloydbInstance
metadata:
  name: my-instance
  namespace: gcp-alloydb-system
spec:
  projectId: my-gcp-project
  # ... AlloyDBInstance spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpalloydbinstances.composition.krateo.io -n gcp-alloydb-system
kubectl get alloydbinstances.alloydb.cnrm.cloud.google.com -A
```
