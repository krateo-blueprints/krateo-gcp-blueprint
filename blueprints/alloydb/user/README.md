# Krateo Blueprint — Google Cloud Alloydb AlloyDBUser

> Generated by `tools/kccgen` from the Config Connector `AlloyDBUser` CRD (`alloydb.cnrm.cloud.google.com`).

Provisions a Google Cloud Alloydb **AlloyDBUser** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `alloydb.cnrm.cloud.google.com/v1beta1` `AlloyDBUser` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpAlloydbUser` Composition you create
becomes a Google Cloud AlloyDBUser.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector AlloyDBUser spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-alloydb-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpAlloydbUser type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpAlloydbUser` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpalloydbusers`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-alloydb-user`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpAlloydbUser
metadata:
  name: my-user
  namespace: gcp-alloydb-system
spec:
  projectId: my-gcp-project
  # ... AlloyDBUser spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpalloydbusers.composition.krateo.io -n gcp-alloydb-system
kubectl get alloydbusers.alloydb.cnrm.cloud.google.com -A
```
