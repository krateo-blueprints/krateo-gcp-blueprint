# Krateo Blueprint — Google Cloud Alloydb AlloyDBCluster

> Generated by `tools/kccgen` from the Config Connector `AlloyDBCluster` CRD (`alloydb.cnrm.cloud.google.com`).

Provisions a Google Cloud Alloydb **AlloyDBCluster** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `alloydb.cnrm.cloud.google.com/v1beta1` `AlloyDBCluster` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpAlloydbCluster` Composition you create
becomes a Google Cloud AlloyDBCluster.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector AlloyDBCluster spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-alloydb-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpAlloydbCluster type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpAlloydbCluster` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpalloydbclusters`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-alloydb-cluster`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpAlloydbCluster
metadata:
  name: my-cluster
  namespace: gcp-alloydb-system
spec:
  projectId: my-gcp-project
  # ... AlloyDBCluster spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpalloydbclusters.composition.krateo.io -n gcp-alloydb-system
kubectl get alloydbclusters.alloydb.cnrm.cloud.google.com -A
```
