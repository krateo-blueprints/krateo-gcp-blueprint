# Krateo Blueprint — Google Cloud Privateca PrivateCACAPool

> Generated by `tools/kccgen` from the Config Connector `PrivateCACAPool` CRD (`privateca.cnrm.cloud.google.com`).

Provisions a Google Cloud Privateca **PrivateCACAPool** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `privateca.cnrm.cloud.google.com/v1beta1` `PrivateCACAPool` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpPrivatecaCapool` Composition you create
becomes a Google Cloud PrivateCACAPool.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector PrivateCACAPool spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-privateca-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpPrivatecaCapool type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpPrivatecaCapool` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpprivatecacapools`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-privateca-capool`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpPrivatecaCapool
metadata:
  name: my-capool
  namespace: gcp-privateca-system
spec:
  projectId: my-gcp-project
  # ... PrivateCACAPool spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpprivatecacapools.composition.krateo.io -n gcp-privateca-system
kubectl get privatecacapools.privateca.cnrm.cloud.google.com -A
```
