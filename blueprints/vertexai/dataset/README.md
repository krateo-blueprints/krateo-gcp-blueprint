# Krateo Blueprint — Google Cloud Vertexai VertexAIDataset

> Generated by `tools/kccgen` from the Config Connector `VertexAIDataset` CRD (`vertexai.cnrm.cloud.google.com`).

Provisions a Google Cloud Vertexai **VertexAIDataset** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `vertexai.cnrm.cloud.google.com/v1beta1` `VertexAIDataset` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpVertexaiDataset` Composition you create
becomes a Google Cloud VertexAIDataset.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector VertexAIDataset spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-vertexai-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpVertexaiDataset type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpVertexaiDataset` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpvertexaidatasets`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-vertexai-dataset`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpVertexaiDataset
metadata:
  name: my-dataset
  namespace: gcp-vertexai-system
spec:
  projectId: my-gcp-project
  # ... VertexAIDataset spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpvertexaidatasets.composition.krateo.io -n gcp-vertexai-system
kubectl get vertexaidatasets.vertexai.cnrm.cloud.google.com -A
```
