# Krateo Blueprint — Google Cloud Servicedirectory ServiceDirectoryService

> Generated by `tools/kccgen` from the Config Connector `ServiceDirectoryService` CRD (`servicedirectory.cnrm.cloud.google.com`).

Provisions a Google Cloud Servicedirectory **ServiceDirectoryService** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `servicedirectory.cnrm.cloud.google.com/v1beta1` `ServiceDirectoryService` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpServicedirectoryService` Composition you create
becomes a Google Cloud ServiceDirectoryService.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector ServiceDirectoryService spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-servicedirectory-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpServicedirectoryService type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpServicedirectoryService` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpservicedirectoryservices`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-servicedirectory-service`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpServicedirectoryService
metadata:
  name: my-service
  namespace: gcp-servicedirectory-system
spec:
  projectId: my-gcp-project
  # ... ServiceDirectoryService spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpservicedirectoryservices.composition.krateo.io -n gcp-servicedirectory-system
kubectl get servicedirectoryservices.servicedirectory.cnrm.cloud.google.com -A
```
