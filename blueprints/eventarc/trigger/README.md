# Krateo Blueprint — Google Cloud Eventarc EventarcTrigger

> Generated by `tools/kccgen` from the Config Connector `EventarcTrigger` CRD (`eventarc.cnrm.cloud.google.com`).

Provisions a Google Cloud Eventarc **EventarcTrigger** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `eventarc.cnrm.cloud.google.com/v1beta1` `EventarcTrigger` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpEventarcTrigger` Composition you create
becomes a Google Cloud EventarcTrigger.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector EventarcTrigger spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-eventarc-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpEventarcTrigger type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpEventarcTrigger` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpeventarctriggers`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-eventarc-trigger`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpEventarcTrigger
metadata:
  name: my-trigger
  namespace: gcp-eventarc-system
spec:
  projectId: my-gcp-project
  # ... EventarcTrigger spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpeventarctriggers.composition.krateo.io -n gcp-eventarc-system
kubectl get eventarctriggers.eventarc.cnrm.cloud.google.com -A
```
