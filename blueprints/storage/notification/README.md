# Krateo Blueprint — Google Cloud Storage StorageNotification

> Generated by `tools/kccgen` from the Config Connector `StorageNotification` CRD (`storage.cnrm.cloud.google.com`).

Provisions a Google Cloud Storage **StorageNotification** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `storage.cnrm.cloud.google.com/v1beta1` `StorageNotification` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpStorageNotification` Composition you create
becomes a Google Cloud StorageNotification.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector StorageNotification spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-storage-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpStorageNotification type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpStorageNotification` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpstoragenotifications`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-storage-notification`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpStorageNotification
metadata:
  name: my-notification
  namespace: gcp-storage-system
spec:
  projectId: my-gcp-project
  # ... StorageNotification spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpstoragenotifications.composition.krateo.io -n gcp-storage-system
kubectl get storagenotifications.storage.cnrm.cloud.google.com -A
```
