# Krateo Blueprint — Google Cloud Logging LoggingLogMetric

> Generated by `tools/kccgen` from the Config Connector `LoggingLogMetric` CRD (`logging.cnrm.cloud.google.com`).

Provisions a Google Cloud Logging **LoggingLogMetric** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `logging.cnrm.cloud.google.com/v1beta1` `LoggingLogMetric` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpLoggingLogmetric` Composition you create
becomes a Google Cloud LoggingLogMetric.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector LoggingLogMetric spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-logging-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpLoggingLogmetric type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpLoggingLogmetric` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcplogginglogmetrics`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-logging-logmetric`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpLoggingLogmetric
metadata:
  name: my-logmetric
  namespace: gcp-logging-system
spec:
  projectId: my-gcp-project
  # ... LoggingLogMetric spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcplogginglogmetrics.composition.krateo.io -n gcp-logging-system
kubectl get logginglogmetrics.logging.cnrm.cloud.google.com -A
```
