# Krateo Blueprint — Google Cloud Datafusion DataFusionInstance

> Generated by `tools/kccgen` from the Config Connector `DataFusionInstance` CRD (`datafusion.cnrm.cloud.google.com`).

Provisions a Google Cloud Datafusion **DataFusionInstance** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `datafusion.cnrm.cloud.google.com/v1beta1` `DataFusionInstance` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpDatafusionInstance` Composition you create
becomes a Google Cloud DataFusionInstance.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector DataFusionInstance spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-datafusion-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpDatafusionInstance type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpDatafusionInstance` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpdatafusioninstances`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-datafusion-instance`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpDatafusionInstance
metadata:
  name: my-instance
  namespace: gcp-datafusion-system
spec:
  projectId: my-gcp-project
  # ... DataFusionInstance spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpdatafusioninstances.composition.krateo.io -n gcp-datafusion-system
kubectl get datafusioninstances.datafusion.cnrm.cloud.google.com -A
```
