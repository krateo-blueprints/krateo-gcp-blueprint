# Krateo Blueprint — Google Cloud Binaryauthorization BinaryAuthorizationAttestor

> Generated by `tools/kccgen` from the Config Connector `BinaryAuthorizationAttestor` CRD (`binaryauthorization.cnrm.cloud.google.com`).

Provisions a Google Cloud Binaryauthorization **BinaryAuthorizationAttestor** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `binaryauthorization.cnrm.cloud.google.com/v1beta1` `BinaryAuthorizationAttestor` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpBinaryauthorizationAttestor` Composition you create
becomes a Google Cloud BinaryAuthorizationAttestor.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector BinaryAuthorizationAttestor spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-binaryauthorization-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpBinaryauthorizationAttestor type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpBinaryauthorizationAttestor` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpbinaryauthorizationattestors`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-binaryauthorization-attestor`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpBinaryauthorizationAttestor
metadata:
  name: my-attestor
  namespace: gcp-binaryauthorization-system
spec:
  projectId: my-gcp-project
  # ... BinaryAuthorizationAttestor spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpbinaryauthorizationattestors.composition.krateo.io -n gcp-binaryauthorization-system
kubectl get binaryauthorizationattestors.binaryauthorization.cnrm.cloud.google.com -A
```
