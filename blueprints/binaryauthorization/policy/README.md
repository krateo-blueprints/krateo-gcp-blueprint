# Krateo Blueprint — Google Cloud Binaryauthorization BinaryAuthorizationPolicy

> Generated by `tools/kccgen` from the Config Connector `BinaryAuthorizationPolicy` CRD (`binaryauthorization.cnrm.cloud.google.com`).

Provisions a Google Cloud Binaryauthorization **BinaryAuthorizationPolicy** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `binaryauthorization.cnrm.cloud.google.com/v1beta1` `BinaryAuthorizationPolicy` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpBinaryauthorizationPolicy` Composition you create
becomes a Google Cloud BinaryAuthorizationPolicy.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector BinaryAuthorizationPolicy spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-binaryauthorization-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpBinaryauthorizationPolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpBinaryauthorizationPolicy` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpbinaryauthorizationpolicies`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-binaryauthorization-policy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpBinaryauthorizationPolicy
metadata:
  name: my-policy
  namespace: gcp-binaryauthorization-system
spec:
  projectId: my-gcp-project
  # ... BinaryAuthorizationPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpbinaryauthorizationpolicies.composition.krateo.io -n gcp-binaryauthorization-system
kubectl get binaryauthorizationpolicys.binaryauthorization.cnrm.cloud.google.com -A
```
