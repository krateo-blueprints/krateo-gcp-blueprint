# Krateo Blueprint — Google Cloud Secretmanager SecretManagerSecret

> Generated by `tools/kccgen` from the Config Connector `SecretManagerSecret` CRD (`secretmanager.cnrm.cloud.google.com`).

Provisions a Google Cloud Secretmanager **SecretManagerSecret** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `secretmanager.cnrm.cloud.google.com/v1beta1` `SecretManagerSecret` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpSecretmanagerSecret` Composition you create
becomes a Google Cloud SecretManagerSecret.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector SecretManagerSecret spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-secretmanager-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpSecretmanagerSecret type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpSecretmanagerSecret` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpsecretmanagersecrets`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-secretmanager-secret`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpSecretmanagerSecret
metadata:
  name: my-secret
  namespace: gcp-secretmanager-system
spec:
  projectId: my-gcp-project
  # ... SecretManagerSecret spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpsecretmanagersecrets.composition.krateo.io -n gcp-secretmanager-system
kubectl get secretmanagersecrets.secretmanager.cnrm.cloud.google.com -A
```
