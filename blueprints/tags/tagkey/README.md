# Krateo Blueprint — Google Cloud Tags TagsTagKey

> Generated by `tools/kccgen` from the Config Connector `TagsTagKey` CRD (`tags.cnrm.cloud.google.com`).

Provisions a Google Cloud Tags **TagsTagKey** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `tags.cnrm.cloud.google.com/v1beta1` `TagsTagKey` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpTagsTagkey` Composition you create
becomes a Google Cloud TagsTagKey.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector TagsTagKey spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-tags-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpTagsTagkey type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpTagsTagkey` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcptagstagkeys`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-tags-tagkey`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpTagsTagkey
metadata:
  name: my-tagkey
  namespace: gcp-tags-system
spec:
  projectId: my-gcp-project
  # ... TagsTagKey spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcptagstagkeys.composition.krateo.io -n gcp-tags-system
kubectl get tagstagkeys.tags.cnrm.cloud.google.com -A
```
