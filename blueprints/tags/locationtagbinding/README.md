# Krateo Blueprint — Google Cloud Tags TagsLocationTagBinding

> Generated by `tools/kccgen` from the Config Connector `TagsLocationTagBinding` CRD (`tags.cnrm.cloud.google.com`).

Provisions a Google Cloud Tags **TagsLocationTagBinding** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `tags.cnrm.cloud.google.com/v1beta1` `TagsLocationTagBinding` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpTagsLocationtagbinding` Composition you create
becomes a Google Cloud TagsLocationTagBinding.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector TagsLocationTagBinding spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-tags-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpTagsLocationtagbinding type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpTagsLocationtagbinding` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcptagslocationtagbindings`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-tags-locationtagbinding`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpTagsLocationtagbinding
metadata:
  name: my-locationtagbinding
  namespace: gcp-tags-system
spec:
  projectId: my-gcp-project
  # ... TagsLocationTagBinding spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcptagslocationtagbindings.composition.krateo.io -n gcp-tags-system
kubectl get tagslocationtagbindings.tags.cnrm.cloud.google.com -A
```
