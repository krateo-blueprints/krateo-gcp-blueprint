# Krateo Blueprint — Google Cloud Certificatemanager CertificateManagerCertificateMap

> Generated by `tools/kccgen` from the Config Connector `CertificateManagerCertificateMap` CRD (`certificatemanager.cnrm.cloud.google.com`).

Provisions a Google Cloud Certificatemanager **CertificateManagerCertificateMap** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `certificatemanager.cnrm.cloud.google.com/v1beta1` `CertificateManagerCertificateMap` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpCertificatemanagerCertificatemap` Composition you create
becomes a Google Cloud CertificateManagerCertificateMap.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector CertificateManagerCertificateMap spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-certificatemanager-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpCertificatemanagerCertificatemap type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpCertificatemanagerCertificatemap` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpcertificatemanagercertificatemaps`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-certificatemanager-certificatemap`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpCertificatemanagerCertificatemap
metadata:
  name: my-certificatemap
  namespace: gcp-certificatemanager-system
spec:
  projectId: my-gcp-project
  # ... CertificateManagerCertificateMap spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpcertificatemanagercertificatemaps.composition.krateo.io -n gcp-certificatemanager-system
kubectl get certificatemanagercertificatemaps.certificatemanager.cnrm.cloud.google.com -A
```
