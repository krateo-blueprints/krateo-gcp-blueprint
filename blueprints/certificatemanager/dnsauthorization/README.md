# Krateo Blueprint — Google Cloud Certificatemanager CertificateManagerDNSAuthorization

> Generated by `tools/kccgen` from the Config Connector `CertificateManagerDNSAuthorization` CRD (`certificatemanager.cnrm.cloud.google.com`).

Provisions a Google Cloud Certificatemanager **CertificateManagerDNSAuthorization** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `certificatemanager.cnrm.cloud.google.com/v1beta1` `CertificateManagerDNSAuthorization` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpCertificatemanagerDnsauthorization` Composition you create
becomes a Google Cloud CertificateManagerDNSAuthorization.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector CertificateManagerDNSAuthorization spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-certificatemanager-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpCertificatemanagerDnsauthorization type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpCertificatemanagerDnsauthorization` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpcertificatemanagerdnsauthorizations`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-certificatemanager-dnsauthorization`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpCertificatemanagerDnsauthorization
metadata:
  name: my-dnsauthorization
  namespace: gcp-certificatemanager-system
spec:
  projectId: my-gcp-project
  # ... CertificateManagerDNSAuthorization spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpcertificatemanagerdnsauthorizations.composition.krateo.io -n gcp-certificatemanager-system
kubectl get certificatemanagerdnsauthorizations.certificatemanager.cnrm.cloud.google.com -A
```
