# Krateo Blueprint — Google Cloud Dataflow DataflowFlexTemplateJob

> Generated by `tools/kccgen` from the Config Connector `DataflowFlexTemplateJob` CRD (`dataflow.cnrm.cloud.google.com`).

Provisions a Google Cloud Dataflow **DataflowFlexTemplateJob** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `dataflow.cnrm.cloud.google.com/v1beta1` `DataflowFlexTemplateJob` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpDataflowFlextemplatejob` Composition you create
becomes a Google Cloud DataflowFlexTemplateJob.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector DataflowFlexTemplateJob spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-dataflow-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpDataflowFlextemplatejob type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpDataflowFlextemplatejob` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpdataflowflextemplatejobs`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-dataflow-flextemplatejob`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpDataflowFlextemplatejob
metadata:
  name: my-flextemplatejob
  namespace: gcp-dataflow-system
spec:
  projectId: my-gcp-project
  # ... DataflowFlexTemplateJob spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpdataflowflextemplatejobs.composition.krateo.io -n gcp-dataflow-system
kubectl get dataflowflextemplatejobs.dataflow.cnrm.cloud.google.com -A
```
