# Krateo Blueprint — Google Cloud Monitoring MonitoringMonitoredProject

> Generated by `tools/kccgen` from the Config Connector `MonitoringMonitoredProject` CRD (`monitoring.cnrm.cloud.google.com`).

Provisions a Google Cloud Monitoring **MonitoringMonitoredProject** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `monitoring.cnrm.cloud.google.com/v1beta1` `MonitoringMonitoredProject` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpMonitoringMonitoredproject` Composition you create
becomes a Google Cloud MonitoringMonitoredProject.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector MonitoringMonitoredProject spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-monitoring-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpMonitoringMonitoredproject type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpMonitoringMonitoredproject` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpmonitoringmonitoredprojects`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-monitoring-monitoredproject`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpMonitoringMonitoredproject
metadata:
  name: my-monitoredproject
  namespace: gcp-monitoring-system
spec:
  projectId: my-gcp-project
  # ... MonitoringMonitoredProject spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpmonitoringmonitoredprojects.composition.krateo.io -n gcp-monitoring-system
kubectl get monitoringmonitoredprojects.monitoring.cnrm.cloud.google.com -A
```
