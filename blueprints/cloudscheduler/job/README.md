# Krateo Blueprint — Google Cloud Cloudscheduler CloudSchedulerJob

> Generated by `tools/kccgen` from the Config Connector `CloudSchedulerJob` CRD (`cloudscheduler.cnrm.cloud.google.com`).

Provisions a Google Cloud Cloudscheduler **CloudSchedulerJob** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `cloudscheduler.cnrm.cloud.google.com/v1beta1` `CloudSchedulerJob` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpCloudschedulerJob` Composition you create
becomes a Google Cloud CloudSchedulerJob.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector CloudSchedulerJob spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-cloudscheduler-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpCloudschedulerJob type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpCloudschedulerJob` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpcloudschedulerjobs`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-cloudscheduler-job`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpCloudschedulerJob
metadata:
  name: my-job
  namespace: gcp-cloudscheduler-system
spec:
  projectId: my-gcp-project
  # ... CloudSchedulerJob spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpcloudschedulerjobs.composition.krateo.io -n gcp-cloudscheduler-system
kubectl get cloudschedulerjobs.cloudscheduler.cnrm.cloud.google.com -A
```
