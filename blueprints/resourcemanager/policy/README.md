# Krateo Blueprint — Google Cloud Resourcemanager ResourceManagerPolicy

> Generated by `tools/kccgen` from the Config Connector `ResourceManagerPolicy` CRD (`resourcemanager.cnrm.cloud.google.com`).

Provisions a Google Cloud Resourcemanager **ResourceManagerPolicy** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `resourcemanager.cnrm.cloud.google.com/v1beta1` `ResourceManagerPolicy` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpResourcemanagerPolicy` Composition you create
becomes a Google Cloud ResourceManagerPolicy.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector ResourceManagerPolicy spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-resourcemanager-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpResourcemanagerPolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpResourcemanagerPolicy` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpresourcemanagerpolicies`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-resourcemanager-policy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpResourcemanagerPolicy
metadata:
  name: my-policy
  namespace: gcp-resourcemanager-system
spec:
  projectId: my-gcp-project
  # ... ResourceManagerPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpresourcemanagerpolicies.composition.krateo.io -n gcp-resourcemanager-system
kubectl get resourcemanagerpolicys.resourcemanager.cnrm.cloud.google.com -A
```
