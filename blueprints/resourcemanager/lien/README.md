# Krateo Blueprint — Google Cloud Resourcemanager ResourceManagerLien

> Generated by `tools/kccgen` from the Config Connector `ResourceManagerLien` CRD (`resourcemanager.cnrm.cloud.google.com`).

Provisions a Google Cloud Resourcemanager **ResourceManagerLien** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `resourcemanager.cnrm.cloud.google.com/v1beta1` `ResourceManagerLien` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpResourcemanagerLien` Composition you create
becomes a Google Cloud ResourceManagerLien.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector ResourceManagerLien spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-resourcemanager-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpResourcemanagerLien type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpResourcemanagerLien` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpresourcemanagerliens`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-resourcemanager-lien`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpResourcemanagerLien
metadata:
  name: my-lien
  namespace: gcp-resourcemanager-system
spec:
  projectId: my-gcp-project
  # ... ResourceManagerLien spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpresourcemanagerliens.composition.krateo.io -n gcp-resourcemanager-system
kubectl get resourcemanagerliens.resourcemanager.cnrm.cloud.google.com -A
```
