# Krateo Blueprint — Google Cloud Spanner SpannerDatabase

> Generated by `tools/kccgen` from the Config Connector `SpannerDatabase` CRD (`spanner.cnrm.cloud.google.com`).

Provisions a Google Cloud Spanner **SpannerDatabase** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `spanner.cnrm.cloud.google.com/v1beta1` `SpannerDatabase` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpSpannerDatabase` Composition you create
becomes a Google Cloud SpannerDatabase.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector SpannerDatabase spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-spanner-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpSpannerDatabase type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpSpannerDatabase` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpspannerdatabases`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-spanner-database`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpSpannerDatabase
metadata:
  name: my-database
  namespace: gcp-spanner-system
spec:
  projectId: my-gcp-project
  # ... SpannerDatabase spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpspannerdatabases.composition.krateo.io -n gcp-spanner-system
kubectl get spannerdatabases.spanner.cnrm.cloud.google.com -A
```
