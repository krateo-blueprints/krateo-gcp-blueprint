# Krateo Blueprint — Google Cloud Recaptchaenterprise RecaptchaEnterpriseKey

> Generated by `tools/kccgen` from the Config Connector `RecaptchaEnterpriseKey` CRD (`recaptchaenterprise.cnrm.cloud.google.com`).

Provisions a Google Cloud Recaptchaenterprise **RecaptchaEnterpriseKey** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `recaptchaenterprise.cnrm.cloud.google.com/v1beta1` `RecaptchaEnterpriseKey` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpRecaptchaenterpriseKey` Composition you create
becomes a Google Cloud RecaptchaEnterpriseKey.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector RecaptchaEnterpriseKey spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-recaptchaenterprise-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpRecaptchaenterpriseKey type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpRecaptchaenterpriseKey` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcprecaptchaenterprisekeys`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-recaptchaenterprise-key`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpRecaptchaenterpriseKey
metadata:
  name: my-key
  namespace: gcp-recaptchaenterprise-system
spec:
  projectId: my-gcp-project
  # ... RecaptchaEnterpriseKey spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcprecaptchaenterprisekeys.composition.krateo.io -n gcp-recaptchaenterprise-system
kubectl get recaptchaenterprisekeys.recaptchaenterprise.cnrm.cloud.google.com -A
```
