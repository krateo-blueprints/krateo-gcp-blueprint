# Krateo Blueprint — Google Cloud Dataproc DataprocCluster

> Generated by `tools/kccgen` from the Config Connector `DataprocCluster` CRD (`dataproc.cnrm.cloud.google.com`).

Provisions a Google Cloud Dataproc **DataprocCluster** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `dataproc.cnrm.cloud.google.com/v1beta1` `DataprocCluster` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpDataprocCluster` Composition you create
becomes a Google Cloud DataprocCluster.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector DataprocCluster spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-dataproc-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpDataprocCluster type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpDataprocCluster` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpdataprocclusters`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-dataproc-cluster`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpDataprocCluster
metadata:
  name: my-cluster
  namespace: gcp-dataproc-system
spec:
  projectId: my-gcp-project
  # ... DataprocCluster spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpdataprocclusters.composition.krateo.io -n gcp-dataproc-system
kubectl get dataprocclusters.dataproc.cnrm.cloud.google.com -A
```
