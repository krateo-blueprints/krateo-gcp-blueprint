# Krateo Blueprint — Google Cloud Containerattached ContainerAttachedCluster

> Generated by `tools/kccgen` from the Config Connector `ContainerAttachedCluster` CRD (`containerattached.cnrm.cloud.google.com`).

Provisions a Google Cloud Containerattached **ContainerAttachedCluster** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `containerattached.cnrm.cloud.google.com/v1beta1` `ContainerAttachedCluster` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpContainerattachedCluster` Composition you create
becomes a Google Cloud ContainerAttachedCluster.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector ContainerAttachedCluster spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-containerattached-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpContainerattachedCluster type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpContainerattachedCluster` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpcontainerattachedclusters`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-containerattached-cluster`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpContainerattachedCluster
metadata:
  name: my-cluster
  namespace: gcp-containerattached-system
spec:
  projectId: my-gcp-project
  # ... ContainerAttachedCluster spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpcontainerattachedclusters.composition.krateo.io -n gcp-containerattached-system
kubectl get containerattachedclusters.containerattached.cnrm.cloud.google.com -A
```
