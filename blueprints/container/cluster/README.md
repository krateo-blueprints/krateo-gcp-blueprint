# Krateo Blueprint — Google Cloud Container ContainerCluster

> Generated by `tools/kccgen` from the Config Connector `ContainerCluster` CRD (`container.cnrm.cloud.google.com`).

Provisions a Google Cloud Container **ContainerCluster** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `container.cnrm.cloud.google.com/v1beta1` `ContainerCluster` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpContainerCluster` Composition you create
becomes a Google Cloud ContainerCluster.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector ContainerCluster spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-container-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpContainerCluster type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpContainerCluster` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpcontainerclusters`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-container-cluster`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpContainerCluster
metadata:
  name: my-cluster
  namespace: gcp-container-system
spec:
  projectId: my-gcp-project
  # ... ContainerCluster spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpcontainerclusters.composition.krateo.io -n gcp-container-system
kubectl get containerclusters.container.cnrm.cloud.google.com -A
```
