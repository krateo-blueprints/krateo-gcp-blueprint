# Krateo Blueprint — Google Cloud Cloudidentity CloudIdentityMembership

> Generated by `tools/kccgen` from the Config Connector `CloudIdentityMembership` CRD (`cloudidentity.cnrm.cloud.google.com`).

Provisions a Google Cloud Cloudidentity **CloudIdentityMembership** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `cloudidentity.cnrm.cloud.google.com/v1beta1` `CloudIdentityMembership` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpCloudidentityMembership` Composition you create
becomes a Google Cloud CloudIdentityMembership.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector CloudIdentityMembership spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-cloudidentity-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpCloudidentityMembership type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpCloudidentityMembership` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpcloudidentitymemberships`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-cloudidentity-membership`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpCloudidentityMembership
metadata:
  name: my-membership
  namespace: gcp-cloudidentity-system
spec:
  projectId: my-gcp-project
  # ... CloudIdentityMembership spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpcloudidentitymemberships.composition.krateo.io -n gcp-cloudidentity-system
kubectl get cloudidentitymemberships.cloudidentity.cnrm.cloud.google.com -A
```
