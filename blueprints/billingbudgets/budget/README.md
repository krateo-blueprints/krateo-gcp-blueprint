# Krateo Blueprint — Google Cloud Billingbudgets BillingBudgetsBudget

> Generated by `tools/kccgen` from the Config Connector `BillingBudgetsBudget` CRD (`billingbudgets.cnrm.cloud.google.com`).

Provisions a Google Cloud Billingbudgets **BillingBudgetsBudget** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `billingbudgets.cnrm.cloud.google.com/v1beta1` `BillingBudgetsBudget` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpBillingbudgetsBudget` Composition you create
becomes a Google Cloud BillingBudgetsBudget.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector BillingBudgetsBudget spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-billingbudgets-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpBillingbudgetsBudget type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpBillingbudgetsBudget` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpbillingbudgetsbudgets`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-billingbudgets-budget`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpBillingbudgetsBudget
metadata:
  name: my-budget
  namespace: gcp-billingbudgets-system
spec:
  projectId: my-gcp-project
  # ... BillingBudgetsBudget spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpbillingbudgetsbudgets.composition.krateo.io -n gcp-billingbudgets-system
kubectl get billingbudgetsbudgets.billingbudgets.cnrm.cloud.google.com -A
```
