# Krateo Blueprint — Google Cloud Edgecontainer EdgeContainerNodePool

> Generated by `tools/kccgen` from the Config Connector `EdgeContainerNodePool` CRD (`edgecontainer.cnrm.cloud.google.com`).

Provisions a Google Cloud Edgecontainer **EdgeContainerNodePool** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `edgecontainer.cnrm.cloud.google.com/v1beta1` `EdgeContainerNodePool` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpEdgecontainerNodepool` Composition you create
becomes a Google Cloud EdgeContainerNodePool.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector EdgeContainerNodePool spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-edgecontainer-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpEdgecontainerNodepool type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpEdgecontainerNodepool` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpedgecontainernodepools`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-edgecontainer-nodepool`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpEdgecontainerNodepool
metadata:
  name: my-nodepool
  namespace: gcp-edgecontainer-system
spec:
  projectId: my-gcp-project
  # ... EdgeContainerNodePool spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpedgecontainernodepools.composition.krateo.io -n gcp-edgecontainer-system
kubectl get edgecontainernodepools.edgecontainer.cnrm.cloud.google.com -A
```
