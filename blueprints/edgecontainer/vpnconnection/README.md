# Krateo Blueprint — Google Cloud Edgecontainer EdgeContainerVpnConnection

> Generated by `tools/kccgen` from the Config Connector `EdgeContainerVpnConnection` CRD (`edgecontainer.cnrm.cloud.google.com`).

Provisions a Google Cloud Edgecontainer **EdgeContainerVpnConnection** through
[Config Connector](https://cloud.google.com/config-connector/docs/overview). The chart renders a
native `edgecontainer.cnrm.cloud.google.com/v1beta1` `EdgeContainerVpnConnection` resource; the Config Connector controller
reconciles it into the real Google Cloud resource and reports status back.

Once the `CompositionDefinition` is applied, every `GcpEdgecontainerVpnconnection` Composition you create
becomes a Google Cloud EdgeContainerVpnConnection.

Upstream stability level of this resource: **stable**.

## Prerequisites

- **Config Connector installed** in the cluster — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md).
- **Google Cloud credentials configured** — Workload Identity (recommended) or a service-account
  key, plus a `ConfigConnectorContext` in the target namespace. See
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the Config Connector EdgeContainerVpnConnection spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `projectId` field sets the
`cnrm.cloud.google.com/project-id` annotation; leave it empty to inherit the project from the
namespace, or when the spec already carries a `projectRef`.

## How to install

```sh
kubectl create namespace gcp-edgecontainer-system
kubectl apply -f compositiondefinition.yaml   # publishes the GcpEdgecontainerVpnconnection type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `GcpEdgecontainerVpnconnection` Composition type (`composition.krateo.io/v0-1-0`,
plural `gcpedgecontainervpnconnections`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/gcp-edgecontainer-vpnconnection`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: GcpEdgecontainerVpnconnection
metadata:
  name: my-vpnconnection
  namespace: gcp-edgecontainer-system
spec:
  projectId: my-gcp-project
  # ... EdgeContainerVpnConnection spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get gcpedgecontainervpnconnections.composition.krateo.io -n gcp-edgecontainer-system
kubectl get edgecontainervpnconnections.edgecontainer.cnrm.cloud.google.com -A
```
